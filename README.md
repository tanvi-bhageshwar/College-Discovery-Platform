# College Explorer & Predictor

An elegant, fully-featured, and modern web application designed to help senior high school and pre-university students discover colleges, calculate admission probabilities using major global standardized exams, saved-colleges management, and dynamically classify institutes into Domestic (National) and Overseas (International) options.

🎨 **Cosmic Slate Theme** | ⚡ **React 19, TypeScript & Vite** | 🍃 **Tailwind CSS v4**

---

## 🚀 Key Features

- **College Database**: Comprehensive list of colleges with filters for regions, study domains (Engineering, Business, Science, Medicine, Arts), and tuition fees.
- **Unified Standardized Exams Support**: Admission predictability scoring across international and national tests:
  - **SAT / ACT** (United States, Global)
  - **JEE Advanced / JEE Main** (India)
  - **BITSAT** (India)
  - **CUET** (India)
  - **VITEEE & State CETs** (regional)
- **Dynamic National vs. International Classification**: 
  - Change your "Home Country" dynamically.
  - Automatically filters college lists into **National** (within your home region) and **International** (overseas) catalogs.
- **Regional Admissions Comparison Matcher**: 
  - Interactive comparison boards contrast tuition expenses (average annual cost) and match probabilities between domestic and foreign options.
- **Shortlisting Desk**: Bookmarks and saves custom colleges to browser session cache, with instantaneous deep profiling links.
- **Dynamic Reviews & Feedback**: Users can leave and read structural, localized reviews of each college on their full-profile drawers.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Core**: React 19 (Hooks, Context, Memoization), TypeScript 5+
- **Build System**: Vite 6 (Highly optimized asset bundling)
- **Styling**: Tailwind CSS v4, Lucide React (featherweight SVG icons)
- **Transitions**: Smooth animations and route states powered by CSS keyframes and modular, accessible layouts.

## 💻 Local Workspace Configuration

To run this project locally, make sure you have **Node.js** (v18 or higher recommended) and **npm** installed.

### 1. Clone & Install Dependencies
```bash
# Clone this repository or extract the ZIP
cd college-explorer

# Install the correct packages
npm install
```

### 2. Launch Development Server
```bash
npm run dev
```
By default, Vite will start the development server. Check your terminal output and navigate to:
`http://localhost:3000` or `http://localhost:5173` (depending on environment binding).
